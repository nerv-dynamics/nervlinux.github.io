Nerv for organisations

Open source, all of it

Nerv and every tool in it are open source under Apache-2.0: the base system and its kernel patches, umalloc, geofront, cage, nerv-install, axon, 9P CPU sharing, Plexus and S2. Patches to other projects keep their original licences. Apache-2.0 includes a patent grant.

Your engineers can read every line, build it themselves and run exactly what your fleet runs. Only builds signed by Nerv Dynamics carry the Nerv name.

The management plane

One place to run a fleet of GB10 and GB300 machines under one set of rules: which GPUs and CPUs serve which teams, which machines are enrolled, which generation each one runs, and what they report. It runs on your own hardware, connected or fully air-gapped, and its source is available to customers for audit.

Machines fetch signed generations and signed policy from the plane and report back. The plane sends no commands, so it has no way into a running machine, and signing rejects anything it should not offer. With a customer-held trust root, generations are signed with your key and nothing reaches your fleet without your signature.

Placement

GPUs assigned, not configured.

Assign GPUs and CPUs to teams, projects and workloads. Through axon, a fleet's accelerators become one pool that work is placed into, and local and remote are the same path.

Quotas

Shared GPUs, hard limits.

Cap memory and compute per tenant on a shared GPU. A workload that reaches its limit gets an out-of-memory error there, and nothing else on the machine is affected.

Enrolment

No shared fleet secret.

Machines join the fleet with their own keys, and new ones install themselves over the network from a machine you already have. Revoking one machine touches no other.

Generations

Canary by machine.

Choose which generation each machine runs and roll a new one out to canaries first. Every machine still falls back on its own if a generation fails to boot.

Access

Single sign-on and an audit log.

Roles, grants that expire, and a record of who changed what. Plexus carries remote access over your own policy, never weaker.

Compliance

Evidence an auditor can use.

A software bill of materials and attestation evidence per machine. Every package records the source commit it was built from, and offline bundles carry signed generations into sites with no internet.

Supported generations

A supported generation is a frozen, validated release of Nerv, kept patched for an agreed period and tested on your hardware and workloads. It holds an accredited configuration still and changes only through your change control, while the rolling release keeps moving to the newest kernel, NVIDIA driver and packages.

No DRM, nothing that calls home

Licences are signed files, checked offline by the management plane, naming your organisation, the number of machines and the expiry date. A fleet that outgrows its licence gets a notice, never a shutdown, and renewal uses a signed machine count produced by the plane. Nothing in Nerv calls home, and nothing outside your site decides what your machines do.

Ship it on hardware you sell

A Nerv base can be signed, locked down with Secure Boot and shipped preinstalled without triggering the installation clause in section 6 of GPL-3, because no GPL-3 package is needed to boot it. The core is Apache, MIT, BSD and 0BSD, with the GPL-2 kernel and LGPL-2.1 libraries. GPL-3 software such as rsync stays available through dnf install for anyone who wants it.

Nerv builds its own C library, allocator, compiler, init, shell, text tools and package manager from source, so its licensing is chosen rather than inherited. Preinstallation on GB10 and GB300 hardware is licensed per unit.

Built in Sweden, held by you

Nerv Dynamics is a Swedish company. Keys are generated on each machine and never leave it, every package is built from source, the source is open to audit, and with a customer-held trust root your key decides what your fleet runs. Nothing about your fleet passes through anyone else, including us.
