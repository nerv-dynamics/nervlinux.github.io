# Sources

Nothing here yet. Both slots render as dashed placeholders until real captures
land, which is deliberate: an obviously empty frame misleads nobody, and
`build.py` counts them on every build.

| file | what | spec |
| --- | --- | --- |
| `desktop.png` | niri on a Nerv machine, OneDark, Nerv Sans Mono in the terminal, real work on screen | 16:9, 2560×1440 |
| `quake.png` | vkQuake in-game, fps overlay visible, on the machine that renders over the network | 16:9, 2560×1440 |

Capture at native resolution, PNG not JPEG, no notifications or half-open
menus. **Not graded.** A screenshot of the system is already in the palette,
because `css/palette.css` and the running machine are generated from the same
`palette.env`; grading one would put it through the palette twice and leave it
the only image on the page that does not match the interface it pictures.

## Two placeholders were tried and removed

Both were third-party and could not be published, which is why they are not in
this repository's history:

- A niri screenshot that was **someone else's machine**: the file manager,
  editor, and shell prompt all showed `adi1090x` on an Archcraft install, and
  the theme was purple rather than OneDark.
- **Quake II RTX carrying an NVIDIA `#RTX500` watermark.** NVIDIA marketing
  material, and the wrong game besides: Nerv packages `nerv-vkquake` and
  `nerv-librequake`, which are Quake 1.

Record what each real capture is here as it lands.
