# Photos

People and hardware. Unlike `assets/shots/`, **everything here goes through
the grade**:

```sh
./grade.sh ~/raw/hero-07.jpg assets/photos/hero.jpg
```

See `docs/imagery.md` for the art direction, the slot list, the masking
constraint on the hero panel, and the generation prompts. `docs/grade.md` has
the mechanism and the knobs.

Raw sources are not committed. The graded file is the asset; the raw one is a
negative and lives wherever you keep negatives.
