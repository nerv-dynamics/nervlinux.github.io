What it does Install

Run your GPU program on a computer you are not sitting at.

Start a CUDA program here and it executes on the GPU in another machine. Same binary, not rebuilt, not containerised. The machine holding the GPU does not have to be running Nerv, or even Linux. A dispatched kernel has run on a remote A800 and returned results bit-identical to native.

How axon does this →

50% more tokens per second than vLLM on Ubuntu.

S2, the inference engine, is part of the image. Not a container and not a Python stack. Models are compiled ahead of time against the silicon they run on, so the runtime replays prepared work instead of deciding what to do on every token.

S2 →

Up to 20% faster than Fedora or Ubuntu, on less power. Boots in four seconds.

Every package is built with LLVM and ThinLTO and tuned for the CPU it runs on, the allocator is mimalloc rather than glibc’s, and temporary files for compilation and the browser live in memory. You notice it unpacking archives, running scripts, compiling, and scrolling a terminal buffer.

System →

CUDA works unmodified, and so does dnf5.

The base is musl with a complete glibc layer beside it, so the NVIDIA driver, runtime and toolkit work on first boot and the Fedora package ecosystem stays one command away. rpm and dnf5 themselves are built pure-musl, which no other musl distribution ships.

System →

Ask the machine which files are actually yours.

atfield measures every byte against the image the system was composed from and the packages that own it, then asks you about whatever is left. It turns “why is this disk full” and “move me to the new machine” into questions with recorded answers.

atfield →

Harder defaults that stay out of the way.

musl with mimalloc gives every process guard pages, randomised allocation and encrypted free lists. Control-flow integrity, stack protection and position-independent executables apply to the whole system, because one compiler built all of it. A bad update costs one reboot, because updates install into the slot you are not running.

What it is

A modern Unix that has left the GNU userland behind. The text tools are Rust uutils, the console is kmscon with proper high-DPI rendering and truecolor, privilege escalation is doas, and the interactive shell is assembled from the tools people actually reach for. None of that breaks scripting, because /bin/sh is still a POSIX shell that behaves the way scripts expect.

Underneath, the whole base system is compiled from source against musl libc patched with mimalloc, using LLVM and clang. That makes the core small, POSIX-clean and consistently hardened. A second glibc userland sits alongside it so that CUDA, Python wheels and vendor binaries run without anyone having to care about the arrangement.

The rest is opinion applied consistently: a kernel stripped of hardware this machine will never have, application defaults chosen for a workstation, and an inference engine and a working Steam setup in the image because those are what the machine is for.
