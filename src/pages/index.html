CPU, GPU, and memory are services.

Decades of old vendor code make it supremely difficult to get a modern Wayland desktop running on musl Linux on NVIDIA hardware. On Nerv, a single daemon holds Vulkan, CUDA, NVML, and all the vendor libraries. Buffers are shared between processes, not copied. A crashing program takes down its connection, not the desktop. An unmodified build of Quake opens an ordinary window on the local desktop and renders on an AMD card on a Windows PC, as if the card were installed locally. Things locked behind hardware SKUs become available too, such as GPUDirect-style RDMA, MIG-style partitioning, and GPUs pooled across a fleet. Even nvidia-smi works as expected, unlike on DGX OS :)

Nerv also speaks 9P2000.L, which means you can run your programs on the cores of another Nerv computer to increase performance or save power.

The rest of the time, it is just a very good computer.
