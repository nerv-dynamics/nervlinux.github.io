Nerv Linux

A Linux distribution for unified-memory GPU workstations. Every package in the base system is compiled from source against musl and LLVM for one of three hardware targets. The NVIDIA driver, CUDA runtime and toolkit are part of the image and work on first boot.

The goal it is built around: an accelerated Wayland desktop on musl with the proprietary NVIDIA driver. No distribution ships one, because a musl process cannot load the vendor's glibc EGL. Nerv puts a boundary there instead.

Why

Linux runs on everything, so no general-purpose distribution can assume anything. Options accumulate, old behaviour is preserved indefinitely, and portability wins every argument it has with economy. For a system that has to boot on hardware nobody has built yet, that is the correct trade.

Nerv targets three machines. It can assume the accelerator is an NVIDIA GB10 or an AMD Strix Halo part, that the CPU and GPU share memory, and that every binary on disk came out of the same compiler. Those assumptions pay for the rest of the system: a daemon that owns the GPU and can serve it over a network, one toolchain applied uniformly to every package, and a record of where each file on the machine came from.

Subsystems

System

musl and mimalloc, LLVM with ThinLTO, systemd on musl, and the whole RPM stack — rpm, libsolv, librepo, dnf5 — built and running with no glibc anywhere in its dependency tree.

Userland

Rust uutils in place of GNU coreutils, and the modern CLI tools wired in as defaults. Scripts that expect classic behaviour still run.

axon

One daemon owns the GPU and every process is a client, so the local and remote paths are the same path. CUDA workloads run on another machine with the program unchanged.

atfield

Provenance for every byte on the machine, and a queue of yes/no questions about the parts nothing accounts for.

S2

An inference engine built for one machine and shipped in the image. Everything is budgeted in bytes read per accepted token.

cage

Transactional A/B updates on btrfs subvolumes. An update composes into the slot you are not running.
