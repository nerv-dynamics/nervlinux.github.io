To install Nerv Linux, run this in a Linux terminal on the same network as the machine, and follow the handbook from there.

$ curl -fsSL https://nervlinux.org/install.sh | sh

Downloading and checking a file

Every file is served from repo.nervlinux.org, and each product's latest/ directory is always its newest stable version, so a script can fetch it with curl and no version number:

$ curl -fLO https://repo.nervlinux.org/releases/stable/plexus/latest/plexus-client-linux-x64.tar.gz
$ curl -fLO https://repo.nervlinux.org/releases/stable/plexus/latest/SHA256SUMS
$ curl -fLO https://repo.nervlinux.org/releases/stable/plexus/latest/SHA256SUMS.asc

SHA256SUMS.asc is signed by the Nerv release key, the key that signs the Nerv repository. Check the signature, then the file against it:

$ curl -fLO https://repo.nervlinux.org/keys/RPM-GPG-KEY-nerv
$ sq verify --signer-file RPM-GPG-KEY-nerv --signature-file SHA256SUMS.asc SHA256SUMS
$ sha256sum -c --ignore-missing SHA256SUMS

With GnuPG, gpg --import RPM-GPG-KEY-nerv and then gpg --verify SHA256SUMS.asc SHA256SUMS. On Windows, GnuPG comes with Gpg4win, and Get-FileHash prints a file's SHA-256 to compare with its line in SHA256SUMS.

The Windows installer is not yet signed for Windows itself, so Windows names no publisher for it and warns before it runs. The signature above is what says it is ours.

New versions reach releases/testing/ first, signed by Nerv's build key, RPM-GPG-KEY-nerv-ci, and move here once they have been tested.
