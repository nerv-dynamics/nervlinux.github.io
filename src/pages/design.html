Design

Four subsystems that a distribution can implement and a container, a library or an application cannot. Each has a design document in the repository; these pages are the summary.

axon

The accelerator behind a syscall-like boundary. One daemon owns the device and every process is a client, so the local and remote paths are the same path and a CUDA program can run on another machine unchanged.

atfield

Provenance for every byte on the machine. Evidence is measured, disposition is decided once, and the parts nothing accounts for become a queue of yes/no questions.

S2

An inference engine specialised for one machine and shipped in the image. Everything decidable ahead of time is compiled into replayable graphs; everything else is budgeted in one unit.

cage

Transactional A/B updates. Compose into the inactive slot, prove it boots, promote it, and roll back when it does not.
