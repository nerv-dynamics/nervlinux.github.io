# Palette — Myelin

Nerv Linux uses **Myelin** throughout the OS, so the site uses it too. The site
states no colour of its own.

Myelin is generated by `nerv-theme` from `myelin.palette` and exported as CSS.
`src/vendor/myelin.css` is that export, copied in; `build.py` turns it into
`css/palette.css`; `css/tokens.css` maps it onto the site's semantic names.
To change a colour, change `myelin.palette` in nerv-theme and re-export.

This replaced OneDark, and the change is larger than a recolour. The old
palette was tuned for one background, so the site carried a block of
hand-computed lightness corrections to make it survive on white. Myelin is
authored for both grounds, so those corrections are gone rather than ported.

## The roles

Seven semantic tokens do the structural work, and they flip between themes:

| token | job |
| --- | --- |
| `--myelin-bg` | the page ground |
| `--myelin-surface` | a raised panel, a table header, a terminal bar |
| `--myelin-line` | hairline rules and borders |
| `--myelin-strong` | a control's visible edge |
| `--myelin-subtle` | tertiary text |
| `--myelin-muted` | secondary text |
| `--myelin-fg` | body text |

Underneath them is an absolute neutral scale, `--myelin-n24` through
`--myelin-n100`, which does **not** flip. The semantic tokens point into it.
That distinction matters mechanically: see *Dark first* below.

Each colour ships three ways. `--myelin-blue` is the colour; `--myelin-blue-bright`
is the emphatic one; `--myelin-blue-ink` is the variant meant for **coloured
running text and button fills**, with `--myelin-on-ink` as the text on that
fill. Use `-ink` whenever the colour is carrying words.

## Measured

Every accent clears WCAG AA for body text on its own ground, in both themes,
without adjustment. They also land within 0.15 of each other, which is a
palette that was tuned rather than picked.

| | on dark `#1e1e1e` | on light `#f7f7f7` |
| --- | --- | --- |
| `fg` | 12.51 | 11.79 |
| `muted` | 9.76 | 8.02 |
| `subtle` | 6.53 | 4.97 |
| `strong` | 3.13 | 4.97 |
| accents (all seven) | 8.24–8.28 | 5.34–5.47 |
| `line` | 1.32 | 1.24 |

Two of those are deliberately below 4.5 and are not failures:

- **`line` is decoration.** WCAG 1.4.11 binds controls and meaningful
  graphics, not the hairline rules that carry a layout. They sit low on
  purpose; a 4.5:1 grid would shout.
- **`strong` is a control edge**, which needs 3:1, not 4.5:1. It clears that in
  both themes, which is why `--border-interactive` maps to it.

To check a new value:

```python
def lin(c):
    c /= 255
    return c/12.92 if c <= 0.03928 else ((c+0.055)/1.055)**2.4
def L(h):
    h = h.lstrip('#'); r, g, b = (int(h[i:i+2], 16) for i in (0, 2, 4))
    return 0.2126*lin(r) + 0.7152*lin(g) + 0.0722*lin(b)
def ratio(a, b):
    la, lb = L(a), L(b); hi, lo = max(la, lb), min(la, lb)
    return (hi + 0.05) / (lo + 0.05)
```

## Dark first, which is a site decision

Myelin is **light-first**: its `:root` is light and it switches on
`prefers-color-scheme`. This site has been dark by default since the theme was
added, the hero is artwork built for a dark ground, and the wordmark ships as
two files chosen by theme. Flipping the default would be a redesign, not a
recolour.

So `build.py` swaps the blocks: Myelin's dark values become `:root`, and its
light values apply under `[data-theme="light"]`, which is what the toggle
writes. No value is retyped in the process.

The neutral scale is emitted separately, at `:root`, because it is absolute and
both themes point into it. Getting that wrong is easy and silent: swapping the
blocks wholesale left the dark defaults referring to `--myelin-n24` and friends
when those existed only inside the light selector.

## The terminal shows the palette rather than using it

`.term` blocks take the plain colours, not the `-ink` variants. They are a
picture of what the machine's own terminal looks like, so they should be the
colours the terminal actually uses.

Screenshots are never graded for the same reason: a capture of the system is
already in the palette, because `css/palette.css` and the running machine come
from the same source.
