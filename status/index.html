Status

The rest of this site describes the system. This page is the only place that says how much of it exists. Nerv is in active development and is not yet something to put on a machine you depend on.

SubsystemStateWhat remains
musl base in tree Builds and boots. systemd on musl as PID 1.
packaging stack in tree rpm, libsolv, librepo and dnf5 verified pure-musl. Owed: package the stack as proper RPMs rather than hand-staged, and the self-hosting smoke test.
userland in tree uutils, the replacement set, neovim and the debug tools are built and installed.
cage building A/B install works. Sealing, automatic rollback and the netboot installer are in progress.
axon building Daemon architecture is settled and the transport measurements are in. The packaging half — owning libcuda.so.1 and the device nodes — needs a Nerv box.
display path designed An accelerated Wayland compositor on musl needs a Vulkan boundary, because a musl process cannot load the vendor's glibc EGL. Until that exists the display path keeps glibc.
atfield designed Phase 1 is buildable. Later phases need attribution and read-recency mechanisms that do not exist yet.
S2 designed The model format, residency and speculation designs are written. The engine is not.

STATUS.md in the repository tracks this in detail, including where the running system and the repository disagree. It is updated as the tree changes.
